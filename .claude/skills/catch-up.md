# Catch-up Skill

Get oriented with YabaiSpaces project context.

## When to use
Start of a new session to quickly understand current state.

## What it does
- Reads CONTEXT.md for quick overview
- Reads memory/project-facts.md for key architectural facts
- Reads memory/current-work.md for recent work and next steps
- Summarizes what you need to know

## Usage
```
/catch-up
```

Or just say "catch me up" or "what's the state of things".
